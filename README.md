# stratego-server

Node.js/TypeScript game server for Reversi (primary), Chess, and Checkers.
Provides auth via Google sign-in, WebSocket rooms, matchmaking, discovery,
and per-game leaderboards.

## Dev

```bash
npm install
npm run dev
```

## Test / build

```bash
npm test
npm run build
```

See the client repo for the full plan: `chilusoft/stratego/docs/PLAN.md`.
